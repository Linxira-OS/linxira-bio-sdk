# 身份匹配结构叠合

## 用途

使用坐标身份匹配原子，对两个本地 PDB/mmCIF 结构进行刚体叠合。

## 输入

一个参考结构和一个移动结构，格式为 PDB 或 mmCIF。

## 参数

使用 `--atom` 选择匹配原子名，默认是 CA。

## 输出

返回匹配原子数、拟合前后 RMSD、旋转矩阵、平移向量和警告。

## 示例

```bash
linxira-bio structure superpose reference.pdb mobile.pdb --atom CA --json
```

## 结果解读

按链 ID、残基 ID 和原子名匹配；拟合后 RMSD 越低，表示这些匹配坐标越接近。

## 注意事项

不执行序列比对、残基对应搜索、柔性拟合、对称性搜索或折叠分类。

## 运行时依赖

纯本地 Rust；不需要 Python、R、Java、网络或外部可执行文件。

## 引用

刚体拟合在身份匹配坐标上使用最小二乘旋转和平移。

## 故障排除

确认两个文件至少共享三个不共线且原子名符合参数的匹配原子。
