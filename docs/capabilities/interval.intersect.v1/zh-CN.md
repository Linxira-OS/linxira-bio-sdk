# BED 区间相交

## 用途

按照确定性的零起点、左闭右开坐标语义，统计两组 BED 区间之间的重叠。

## 输入

两个分别表示左侧和右侧区间集的 BED 文件。程序按魔数识别纯文本和 gzip 流；每条
记录至少需要三个制表符分隔列。

## 参数

两个输入路径均为必需参数，输入顺序有意义；`--json` 返回标准分析结果封装。v1
没有链方向或重叠比例过滤参数。

## 输出

返回两侧区间数、重叠对数、两侧唯一被重叠区间数、累计重叠碱基数、各 contig
统计和警告。

## 示例

```bash
linxira-bio interval intersect tests/fixtures/interval-intersect/left.bed tests/fixtures/interval-intersect/right.bed --json
```

## 结果解读

区间按 `[start, end)` 处理，因此首尾相接不算重叠。一个区间可以贡献多个重叠对；
累计重叠碱基按重叠对求和，同一基因组位置可能被重复计入。

## 注意事项

两个输入必须使用相同的参考基因组、坐标约定和 contig 命名。v1 不输出连接后的 BED
记录，也不支持链方向、最小碱基数或重叠比例规则。

## 运行时依赖

纯 Rust 本地能力，无需 Python、R、Java、bedtools 或外部命令行工具。

## 引用

坐标语义遵循 UCSC BED 规范。超出本版本摘要范围的高级区间运算请使用 bedtools。

## 故障排除

零重叠时先检查参考基因组名称和 `chr` 前缀。列缺失、坐标非法或区间长度非正时，
根据错误中的行号定位。
