# 研究队列表质量控制

## 用途

在本地汇总研究队列表的结构、缺失值、重复行、不同取值数量和有限数值范围。本功能仅供科研使用，不生成诊断、风险评分、治疗建议或临床决策。

## 输入

一份列名非空且不重复的 CSV 或 TSV 队列表。

## 参数

必须提供输入路径；分隔符会自动识别。

## 输出

返回行列数量、各列缺失情况、不同取值数量与数值范围。

## 结果解读

缺失值和重复记录用于发现需要复核的数据质量问题，不用于推断受试者状态或结局。

## 注意事项

本功能不会验证临床编码体系、推断诊断，也不能替代数据治理审查。

## 示例

```text
linxira-bio medical cohort-qc participants.tsv --json
```

## 运行时依赖

仅使用本地 Rust；输入数据不会上传。

## 引用

应引用使用的队列、研究方案和数据字典。

## 故障排除

运行前请解决重复列名和不符合 CSV/TSV 格式的记录。
