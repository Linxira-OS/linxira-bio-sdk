# 系统发育树转换

## 用途

验证、标准化、重命名、汇总并按单个叶节点重新定根本地 Newick 树。

## 输入

一个普通或 gzip Newick 树，最多包含 1,000,000 个节点。

## 参数

必须提供 `output`；可选 `reroot_label` 选择一个叶节点，可选 `label_map` 把旧标签映射为新标签。

## 输出

写出标准化 Newick，并返回拓扑计数、深度、总枝长、转换计数、路径和警告。

## 示例

```bash
linxira-bio phylogeny tree input.nwk output.nwk --reroot outgroup --label-map labels.tsv --json
```

## 结果解读

重新定根时，所选叶节点边长会平均分配到新根的两条分支。

## 注意事项

只支持唯一的单叶外群；不会推断树拓扑，也不会生成绘图。

## 运行时依赖

纯本地 Rust；不需要序列比对、建树程序或网络服务。

## 引用

输入输出使用 Newick 括号表示法，并支持带引号标签和注释。

## 故障排除

使用唯一叶标签，避免映射后出现重复标签，并选择尚不存在的输出路径。
