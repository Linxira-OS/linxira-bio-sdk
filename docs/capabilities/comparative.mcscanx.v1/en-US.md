# Genome Collinearity Analysis

## Purpose

Infer collinear gene blocks locally from ordered gene positions and pairwise sequence-similarity hits.

## Inputs

Provide a tab-separated gene-position table with chromosome, gene identifier, start, and end columns, plus a BLAST tabular result whose identifiers match the position table.

## Parameters

The output `.collinearity` path is required. The desktop application derives it beside the primary input.

## Outputs

A text collinearity file generated by the configured native MCScanX executable.

## Examples

```text
linxira-bio comparative mcscanx genes.tsv hits.blast blocks.collinearity --json
```

## Interpretation

Reported blocks depend on gene ordering, similarity-search settings, identifier consistency, and the native tool version. Validate representative anchors before downstream evolutionary interpretation.

## Caveats

This capability wraps the maintained native algorithm; it does not reimplement that algorithm in Rust. The worker invokes the executable directly with an argument vector and does not execute a shell. Malformed gene positions or unmatched identifiers can yield empty or misleading blocks.

## Runtime Dependencies

Requires `MCScanX` on `PATH`, or an executable selected with `LINXIRA_BIO_MCSCANX`. Run the environment audit when the executable is missing.

## Citations

Cite MCScanX, its version, and the sequence-similarity method and parameters used to produce the hits.

## Troubleshooting

Confirm that both inputs are local readable files, gene identifiers agree exactly, and the environment audit reports the native executable as available.
