# 基因组共线性分析

## 用途

根据有序基因位置和成对序列相似性命中结果，在本地推断共线基因区块。

## 输入

提供制表符分隔的基因位置表，列依次为染色体、基因标识、起点和终点；同时提供基因标识与位置表一致的 BLAST 表格结果。

## 参数

必须指定 `.collinearity` 输出路径。桌面应用会在主输入文件旁自动生成该路径。

## 输出

由已配置的 MCScanX 原生可执行文件生成的文本共线性结果。

## 示例

```text
linxira-bio comparative mcscanx genes.tsv hits.blast blocks.collinearity --json
```

## 结果解读

结果取决于基因排序、相似性搜索参数、标识一致性和原生工具版本。进行后续进化解释前，应抽查代表性锚点。

## 注意事项

本能力封装维护中的原生算法，不在 Rust 中重新实现该算法。Worker 使用参数数组直接启动可执行文件，不经过 shell。基因位置格式错误或标识不匹配可能产生空结果或误导性区块。

## 运行时依赖

需要 `PATH` 中存在 `MCScanX`，也可通过 `LINXIRA_BIO_MCSCANX` 指定可执行文件。缺少可执行文件时请运行环境审计。

## 引用

请引用 MCScanX 及其版本，并记录生成相似性命中的方法和参数。

## 故障排除

确认两个输入都是本地可读文件、基因标识完全一致，并检查环境审计是否报告原生可执行文件可用。
