# 预排序基因集富集分析

## 用途

根据有序基因统计量和显式基因集成员表，在本地运行确定性的预排序 GSEA。

## 输入

一个带表头 CSV/TSV 排序表，包含基因标识和有限数值分数；另一个带表头成员表包含基因
和术语标识。可选术语名称与命名空间会被保留。

## 参数

可设置分数指数、映射后基因集最小和最大大小、置换次数及随机种子。默认指数 1、集合
大小 15 到 500、1,000 次置换、种子 0。

## 输出

JSON 返回富集分数、方向、峰值排名、leading-edge 基因、固定种子名义置换 p 值、
Benjamini-Hochberg FDR、映射计数、跳过集合和警告。

## 示例

```bash
linxira-bio enrichment gsea ranks.tsv gene-sets.tsv \
  --min-set-size 15 --max-set-size 500 --permutations 1000 --seed 0 --json
```

## 结果解读

分数按降序排列；并列分数按基因标识稳定排序并产生警告。正负结果表示在所给排序两端
富集，不代表因果方向。

## 注意事项

名义 p 值采用确定性的基因标签置换和加一校正；FDR 是所有受检集合的
Benjamini-Hochberg 校正，并非经典的合并归一化富集分数流程。必须记录排序方法、背景、
基因集版本、参数、种子和置换次数。

## 运行时依赖

纯 Rust 本地运行，无需 Python、R、Java、网络服务或外部程序。

## 引用

应引用原始 GSEA 方法、基因集数据库及版本、排序统计量来源，并报告本实现的置换和多重
检验方法。

## 故障排除

重复排序标识、非有限分数、冲突的术语元数据会被拒绝；覆盖完整排序背景的集合会被跳过，
并返回明确诊断。
