# UpSet 多集合分析

## 用途

汇总 2–64 个生物标识符集合的精确交集，避免高阶 Venn 图难以阅读。

## 输入

本地 CSV/TSV 表格；各列是命名集合，非空单元格是标识符。

## 参数

使用 `--max-intersections N` 限制排序结果，使用 `--include-items` 返回标识符。默认返回最大的 50 个精确交集且不附项目列表。

## 输出

JSON 返回集合大小、并集大小、观察到的交集总数、省略数，以及按计数、阶数和集合名排序的交集。

## 示例

```bash
linxira-bio set upset sets.tsv --max-intersections 100 --json
```

## 结果解读

结合集合大小条形图和精确交集条形图解读。高阶交集表示项目同时属于多个列出的集合，且不属于未列出的集合。

## 注意事项

输入最多 64 列、100 万行和 100 万个唯一标识符。截断只影响显示，集合总量和交集总数仍会返回。

## 运行时依赖

该能力完全在本地 Rust 中运行。

## 引用

应引用构建每个集合时采用的数据来源和筛选规则。

## 故障排除

结果存在省略交集时提高 `--max-intersections`，或在分析前筛选集合。
