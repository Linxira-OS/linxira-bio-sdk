# Ka/Ks 计算

## 用途

为本地密码子比对序列对估算非同义替换率和同义替换率。

## 输入

提供有效的 AXT 密码子比对。每个序列对包含一行名称和两条已比对的编码序列，序列长度必须符合完整密码子要求。

## 参数

选择一种受支持的方法：`NG`、`LWL`、`LPB` 或 `YN`。默认使用 `NG`。

## 输出

由已配置的 KaKs Calculator 原生可执行文件生成的制表符分隔结果。

## 示例

```text
linxira-bio comparative kaks codon-pairs.axt rates.tsv NG --json
```

## 结果解读

应结合比对质量、序列分化程度、基因历史和所选估算方法解释 Ka、Ks 及其比值。仅凭 Ka/Ks 比值不能证明正选择。

## 注意事项

输入必须是生物学上有效的密码子比对，不能使用任意核苷酸比对代替。Worker 使用参数数组直接启动可执行文件，不经过 shell。

## 运行时依赖

需要 `PATH` 中存在 `KaKs_Calculator`，也可通过 `LINXIRA_BIO_KAKS_CALCULATOR` 指定可执行文件。缺少可执行文件时请运行环境审计。

## 引用

请引用 KaKs Calculator 及其版本，并记录所选方法和密码子比对流程。

## 故障排除

重试前检查阅读框、序列对结构、终止密码子和比对长度，并通过环境审计确认可执行文件可用。
