# 批量 RNA-seq 科研工作流

## 用途

以仅限医学组学科研的方式，在本地运行经过验证的两条件批量 RNA-seq 差异表达工作流。

## 输入

提供原始整数计数矩阵和恰好包含两个研究组的样本元数据。ID 必须唯一且一致，每组至少需要两个生物学样本。不要输入直接身份标识或非必要的受保护数据。

## 参数

声明输出目录、特征与样本 ID 列、条件列、参考水平和对比水平。可选 `alpha` 与 `min_total_count` 分别控制结果阈值和拟合前过滤。

## 输出

生成差异表达与归一化计数 CSV，以及标记为 `research-use-only`、`clinical_use: false` 的结果信封。医学入口始终输出仅限科研的诊断提示。

## 示例

```text
linxira-bio workflow run org.linxira.bulk-expression-deseq2 request.json output/result.json
```

在 schema v2 请求中使用 `medical.bulk-rnaseq.v1`。

## 结果解读

统计对比只能作为探索性科研证据。应审查队列构建、混杂因素、重复质量、效应量、调整后 p 值和生物学合理性。

## 注意事项

该能力不诊断疾病、不判断预后、不推荐治疗、不验证生物标志物，也不提供临床解释。它不是医疗器械，不得用于患者个体决策。

## 运行时依赖

与 `expression.differential.v1` 共用稳定 R 4.6.x 和项目隔离的 DESeq2 工作流。不会安装包、修改全局包库、上传网络或使用云端执行。

## 引用

引用 DESeq2、实际包版本、研究设计，以及适用的队列或检测来源。

## 故障排除

运行环境审计，将完整 R 依赖图解析到所选项目包库，移除直接身份标识，并在执行前核对研究对比。
