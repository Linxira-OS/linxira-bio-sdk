# 聚类表达热图

## 用途

为原生 Rust 桌面渲染器准备已排序的表达热图数据。

## 输入

完整的本地 CSV/TSV 表达矩阵，特征标识唯一且所有数值有限。

## 参数

用 `--top-features N` 按样本方差选择最多 200 个特征。默认执行行 z-score，
可用 `--no-scale` 保留输入数值。

## 输出

JSON 包含已排序的行列标签、有限显示矩阵、数值范围、维度和警告。GUI 无需浏览器运行时即可渲染。

## 示例

```bash
linxira-bio expression heatmap matrix.tsv --top-features 50 --json
```

## 结果解读

确认所选特征、样本标签、变换和聚类假设后，再检查协调变化的相对模式。

## 注意事项

特征选择和聚类属于探索性分析，不执行差异表达。样本超过 200 个时采用确定性投影排序，
本地数值分析最多处理 1000 万个矩阵单元格。

## 运行时依赖

方差选择、行缩放、平均连接排序和渲染均为本地 Rust 实现。

## 引用

应引用层次聚类，以及生成矩阵时采用的标准化方法。

## 故障排除

降低 `--top-features` 可改善可读性；只有需要直接比较输入幅度时才关闭行缩放。
