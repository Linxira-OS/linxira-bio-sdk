# 坐标聚合物序列提取

## 用途

从本地 PDB 或 mmCIF 坐标中实际出现的残基身份提取聚合物序列。

## 输入

一个普通、gzip 或 BGZF PDB/mmCIF 坐标文件。

## 参数

提供输入路径；使用 `--json` 返回标准结果信封。

## 输出

返回所选模型、各链聚合物类型、残基数、序列和警告。

## 示例

```bash
linxira-bio structure sequence structure.pdb --json
```

## 结果解读

序列表示首模型中具有保留坐标记录的残基。

## 注意事项

缺失或未解析残基可能不在结果中，不能自动把它当作完整参考序列。

## 运行时依赖

纯本地 Rust；不需要 Python、R、Java、网络或外部可执行文件。

## 引用

残基名称映射遵循标准蛋白和核酸坐标约定。

## 故障排除

检查未知残基警告，并确认输入包含聚合物原子记录。
