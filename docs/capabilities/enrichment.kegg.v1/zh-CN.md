# KEGG 过度富集分析

## 用途

根据显式 KEGG 关联标识在本地运行通路过度富集分析。

## 输入

查询标识列表和 CSV/TSV 关联表；KEGG 命名空间行及常见通路或 KO 标识定义背景。

## 参数

可设置最小重叠、最多报告术语数和是否返回重叠基因。

## 输出

JSON 返回映射查询、KEGG 背景大小、超几何及校正 p 值、富集倍数和排序通路或 KO。

## 示例

```bash
linxira-bio enrichment kegg genes.txt kegg-associations.tsv --json
```

## 结果解读

结合通路覆盖、物种映射、效应大小和给定背景解读校正显著性。

## 注意事项

不下载、不再分发也不更新 KEGG 数据；用户需要提供具备适当许可的关联表。

## 运行时依赖

计算全部在本地 Rust 中完成，不访问远程通路服务。

## 引用

记录关联来源、物种、版本日期、标识转换、背景和校正方法。

## 故障排除

确认命名空间或术语 ID 表示 KEGG 记录，并保证查询 ID 与关联表一致。
