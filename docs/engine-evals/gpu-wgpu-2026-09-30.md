# M5-G2 wgpu/WGSL 首轮对照（2026-09-30，主机 A）

探针：`gpu-lab gpu-bench`（wgpu 30 / Vulkan 后端 / Intel Arc 130T 核显；同种子合成数据与
M5-G1 CPU 基线逐位一致；计时分相：upload / compute / readback / total）。

## 结论表

| 内核 | GPU（f32/u32） | CPU f64 audit | CPU AVX2+FMA | 一致性 |
| --- | --- | --- | --- | --- |
| pearson v1（逐线程串行链） | compute 14.3 ms | 145–381 ms（10–21×） | 88–100 ms | Δ=4.14e-6 < 1e-5，通过 |
| **pearson v2（workgroup 64 线程 + 树归约）** | **compute 2.9 ms**（**50× f64 / 30× AVX2**） | 同上 | 同上 | **Δ=7.42e-7**（比 v1 小 5.6×），通过 |
| quality-histogram（3 亿碱基，u32 打包） | compute 64–114 ms（运行间波动，iGPU 共享内存） | 94–124 ms（打平） | — | **整数精确匹配**（逐 bin checksum 一致），通过 |
| kmer-count | 未移植：哈希表结构不映射 WGSL，按双实现硬规则落 G3 厂商栈（必做不豁免） | 3,578 ms / 783 MB | — | — |

## 解读

1. **v2 树归约速度与精度双赢**：workgroup 内 64 线程按行 stride 分摊 + shared-memory 树归约，
   compute 从 14.3 ms 降至 **2.9 ms**（4.9×），同时 Δ 从 4.14e-6 降至 **7.42e-7**（5.6×）
   ——log-depth 累积误差天然小于 2000 步串行链，精度策略第 2 条规则（长归约用 tree
   reduction）的实效证据。核显 f32 推荐档对 CPU f64 audit 达 **50×**。
2. **计算型内核核显大胜**：Pearson 列对内积在 Arc 130T（核显！）上 50× 于 CPU f64、
   30× 于 AVX2+FMA——"最弱硬件（核显）+ f32 推荐档跑出性能"叙事的实测证据，且同输入
   f64 audit 档并存、容差可对账（精度契约落地）。
3. **带宽型内核在 iGPU 上无优势是架构必然**：核显显存即系统内存，直方图 GPU 与 CPU
   打平（且付 upload ~60 ms）；该类内核收益看独立显存档（G1/G2），如实记录。
4. **实现修正记录**（过程）：① wgpu `DeviceDescriptor::default()` limits 上限 256 MB，
   3 亿碱基 buffer 需显式 `required_limits: adapter.limits()`；② 直方图 grid-stride 首版
   未按线程分摊，256 线程重复计数恰 256 倍；③ wgpu dispatch 单维上限 65,536——12.4 万
   workgroup 需二维展开（x×y），shader 以 `num_workgroups.x` 换算线性 index。
5. 后续优化空间：v2 每对一组（124,750 组）仍偏保守，subgroup（warp）级 shuffle 归约与
   每组多对的批次化预计仍有余量；与 G3 厂商栈（sycl-rs/cudarc-musa/cutile-rs）同内核
   对照是下一步。

复现：`cd gpu-lab && cargo run --release -- gpu-bench`。
