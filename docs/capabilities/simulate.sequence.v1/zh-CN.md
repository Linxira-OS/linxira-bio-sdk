# 序列模拟

## 用途

以种子化生成合成确定性随机 DNA FASTA——为基准测试、流水线演练与 GPU 一致性参照提供
可字节级复现的燃料。

## 输入

无输入；选项完全决定输出。

## 参数

`--count N` 条序列；`--length N` 固定单一长度，或 `--min-length A --max-length B` 逐
序列均匀抽取。`--gc` 设定 GC 目标百分比（默认 50），`--n-fraction` 设定 N 占比
（默认 0），`--seed` 设定种子（默认 42），`--prefix` 设定标识符前缀（默认 `sim`）。

## 输出

一条记录对应一条请求序列的 FASTA（header 携带长度）与 JSON 汇总：种子、数量、长度
范围、平均长度、实测 GC 百分比与 N 计数。

## 示例

```bash
linxira-bio simulate sequence reference.fa --count 10 --length 100000 --gc 45 --seed 42 --json
```

## 结果解读

实测 GC 含量随序列变长收敛到目标值；短序列的偏差是抽样噪声。种子加选项即复现契约：
相同输入必须逐字节再生成文件。

## 注意事项

序列是独立同分布抽取——不含重复、等值线块或 k-mer 结构。需要结构化基准时，与
`simulate reads` 组合并为各阶段指定不同种子。生成器只使用整数运算；除文档声明的收敛
性外不提供浮点统计保证。

## 运行时依赖

除 CLI 外无依赖——纯 Rust，xoshiro256** 经 SplitMix64 播种。

## 引用

未复现任何外部方法；当模拟数据支撑已发表的对比时，按版本引用本能力。

## 故障排除

再生成文件不一致：种子或某个选项不同——用 JSON 汇总字段与台账记录逐项核对。GC 偏离
目标过大：序列长度不足以收敛；增大 `--length`。
