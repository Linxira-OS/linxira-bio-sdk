# 交互式结构查看器

## 用途

在本地查看 PDB 和 mmCIF 坐标，支持旋转、缩放、平移、多种分子表示、置信度着色和 PNG 截图。

## 输入

本地 PDB 或 mmCIF 文件；可按内容识别 gzip 压缩文件。

## 参数

可选择骨架、球棍或空间填充表示，切换杂原子、氢原子和置信度着色，并交互调整视角。

## 输出

原生桌面交互视图，以及可选的当前相机和表示方式 PNG 截图。

## 示例

```bash
linxira-bio-ui <input.pdb|mmcif>
```

## 结果解读

存在坐标置信度时可按其着色；表示方式只改变几何显示，不改变底层结构数据。

## 注意事项

查看器用于探索，不执行分子动力学、结构验证、对接或临床解释。

## 运行时依赖

原生 Rust egui 程序使用本地图形渲染，不使用 WebView，也不上传坐标。

## 引用

记录结构来源、预测或实验方法、数据库 accession 和本能力版本。

## 故障排除

若渲染不可用，可设置 `LINXIRA_BIO_RENDERER=glow` 或 `wgpu`；同时确认坐标为有限数值且文件包含原子记录。
