# 比对窗口深度

## 用途

流式读取原生 `samtools depth` 输出并在 Rust 侧聚合，为 BAM/CRAM 比对结果计算固定窗口
的深度与覆盖广度指标，获得可扩展到全基因组、无需落地逐位点表的覆盖度剖面。

## 输入

BAM 或 CRAM 比对文件。建议提供坐标排序且带索引的输入；参考序列未内嵌的 CRAM 需能通过
samtools 参考路径配置解析。

## 参数

`--window-size` 设定窗口长度（碱基数，默认 10000，必须为正）。`--min-mq` 与 `--min-bq`
按比对质量和碱基质量过滤（默认 0）。`--threads` 设置 samtools 工作线程（默认 1）。输入与
输出路径必须不同。

## 输出

写出每窗口一行的 TSV（参考名、起始、结束、平均深度、最小、最大、覆盖碱基数、覆盖广度
百分比），坐标为 1 起始闭区间；每条参考的最后一个窗口为部分窗口。JSON 报告原生工具溯源
信息及全文件与逐参考汇总（窗口数、碱基数、覆盖碱基数、广度百分比、平均深度、最大深度）。
深度求和使用精确 64 位整数，均值不存在随规模增长的累积误差。

## 示例

```bash
linxira-bio alignment window-depth aligned.sorted.bam windows.tsv --window-size 10000 --json
```

## 结果解读

平均深度要与覆盖广度百分比一起读：均值高而广度低说明覆盖集中且不均。窗口是基因组分箱
而非独立生物学单元，用于定位覆盖度塌陷区域，不能当作重复样本。被质量过滤的碱基在其位置
计为未覆盖。

## 注意事项

需要 samtools 1.13 及以上（使用无歧义的长旗标 `--min-MQ`/`--min-BQ`）。逐位点流被严格
解析：位置必须按参考分组且递增，与 `samtools depth -aa` 输出一致；手工编辑过的输入会被
拒绝。无比对读段时输出空表并给出警告，而非报错。

## 运行时依赖

原生 `samtools` 可执行文件（环境审计在 alignment-files 类别下探测，可经
`LINXIRA_BIO_SAMTOOLS` 覆盖）。不使用 Python、R 或 Java 运行时。

## 引用

报告窗口深度时引用 samtools 套件：Li 等 2009（Bioinformatics 25:2078-2079）及
samtools-depth 手册页。

## 故障排除

先运行环境审计并检查 samtools 版本（`samtools --version`）。确认比对包含已比对读段；空
窗口表加"无记录"警告表示深度流为空。CRAM 参考序列报错时配置参考路径或转换为 BAM。
