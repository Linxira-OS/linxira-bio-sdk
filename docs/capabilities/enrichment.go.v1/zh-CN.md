# GO 过度富集分析

## 用途

使用显式基因到 GO 关联在本地运行 Gene Ontology 过度富集分析。

## 输入

查询标识列表和 CSV/TSV 关联表；只有语法有效的 `GO:` 标识进入 GO 背景。

## 参数

可设置最小重叠、最多报告术语数和是否返回重叠基因。

## 输出

JSON 返回映射覆盖、GO 背景大小、超几何 p 值、Benjamini-Hochberg 校正值、富集倍数和排序术语。

## 示例

```bash
linxira-bio enrichment go genes.txt go-associations.tsv --json
```

## 结果解读

结合本体命名空间、实验设计、背景覆盖、效应大小和校正 p 值解读。

## 注意事项

不展开本体图，也不做语义冗余消除；应使用有版本记录的关联表。

## 运行时依赖

计算全部在本地 Rust 中完成，无需网络。

## 引用

记录 GO 版本、注释来源、证据筛选、背景和统计校正方法。

## 故障排除

先归一化来源 GO 列，并确认查询标识存在于关联表中。
