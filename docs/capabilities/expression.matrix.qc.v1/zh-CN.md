# 表达矩阵质量控制

## 用途

在本地校验矩形 CSV/TSV 表达矩阵，并汇总维度、缺失、稀疏度、特征标识和样本指标。

## 输入

一个 CSV 或 TSV 矩阵：首行为表头，第一列为特征标识，其余列为样本数值。程序按
魔数识别纯文本和 gzip 流。

## 参数

输入路径为必需参数，分隔符自动识别；`--json` 返回标准分析结果封装。空单元格、
`.`、`NA` 和 `NaN` 视为缺失值。

## 输出

返回分隔符、特征标识列、矩阵维度、总单元格与数值单元格数、缺失值/零值/负值/
重复特征数、零值比例，以及各样本总量、均值、检出特征数和警告。

## 示例

```bash
linxira-bio expression matrix-qc tests/fixtures/expression-matrix/counts.tsv --json
```

## 结果解读

零值与缺失单独统计。负值通常说明矩阵经过转换而非原始计数。样本总量和检出特征
可提示尺度或质量异常，但不能单独确定统计显著性。

## 注意事项

该能力仅执行描述性质控，不做归一化、不读取实验设计、不拟合统计模型、不校正批次
效应，也不计算差异表达。

## 运行时依赖

纯 Rust 本地流式能力，无需 Python、R、Java、pandas 或 Bioconductor。

## 引用

后续原始计数分析应遵循所选方法（例如 DESeq2、edgeR 或 limma-voom）的假设和引用
要求。

## 故障排除

确认表头中的样本名唯一、每行列数一致，且所有非缺失样本单元格都是有限数值。在
模型拟合前处理重复特征标识。
