# annotation.gxf.stats.v1

## 用途

在本地统计 GFF3 或 GTF 注释，不修改输入。

## 输入

- 一个合法的九列 GFF3 或 GTF 文件，坐标为 1-based 闭区间。
- 支持普通文本与 gzip 压缩输入。

## 参数

- `--json`：输出结构化结果信封。

## 输出

记录、指令、序列区域、特征类型、序列 ID、来源、链方向、ID、Parent 与坐标范围统计。

## 示例

```bash
linxira-bio annotation stats input.gff3 --json
```

## 结果解读

在规范化或提取序列前，用特征和序列计数确认注释范围。

## 注意事项

任一记录格式错误都会使整个任务失败；统计不会修复父子关系。

## 运行时依赖

在 Rust core 中本地运行，不需要 Python、R、Java、GPU、容器或网络。

## 引用

未引入外部科学方法；该能力实现确定性的 GFF3/GTF 解析与描述统计。

## 故障排除

确认每条特征记录恰好有九个制表符分隔字段，并检查坐标、链方向和 phase。
