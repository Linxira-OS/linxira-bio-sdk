# 表达长度归一化

## 用途

使用以碱基对为单位的全特征长度表，将本地 CSV 或 TSV 批量表达计数矩阵归一化为 TPM、FPKM 或 RPKM。

## 输入

需要两个输入。矩阵第一列为唯一特征标识，其余列为有限、非负的计数值。长度表恰好两列：特征标识与以 bp 计的长度。支持普通与 gzip 压缩输入。

## 参数

选择 `--method tpm|fpkm|rpkm` 并以 `--lengths` 传入长度表。每个矩阵特征都必须有正的有限长度；长度表缺失的标识会被拒绝，未使用的标识产生警告。输入与输出路径必须不同。

## 输出

写出保持特征与样本顺序的 TSV 矩阵。JSON 报告方法、维度、长度单位、长度统计（最小、中位、最大、零计数特征数）、每样本输入/输出总量、缩放因子与警告。

## 示例

```bash
linxira-bio expression normalize counts.tsv tpm.tsv --method tpm --lengths feature-lengths.tsv --json
```

## 结果解读

TPM 每列之和为一百万，用于跨样本的构成比较。FPKM 与 RPKM 在历史上分别对应单端与双端命名，计算完全一致；两者都同时校正长度与库大小。

## 注意事项

缺失长度、非正长度、零库大小以及每千碱基速率全为零的样本会被拒绝。这些值是归一化速率而非计数；不要送入基于计数的统计模型。本地分析上限为一千万矩阵单元格。

## 运行时依赖

实现为本地 Rust，不需要 Python、R 或 Java 运行时。

## 引用

报告 TPM 时引用 Wagner 等 2012（Theory Biosci. 111:1-21）。报告 FPKM 或 RPKM 时引用 Mortazavi 等 2008（Nat. Methods 5:621-628）与 Trapnell 等 2010（Nat. Biotechnol. 28:511-515）。

## 故障排除

先运行矩阵质控并解决缺失值与重复标识。确认长度表以正长度覆盖每个特征，且长度单位是碱基对而不是千碱基。
