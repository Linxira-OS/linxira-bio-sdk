# eggNOG 注释归一化

## 用途

把已经完成的 eggNOG-mapper 注释表归一化为稳定的本地字段。

## 输入

包含 `#query` 表头的标准制表符注释文件；可按内容读取 gzip。

## 参数

提供输入和新的输出 TSV 路径；不接受数据库访问或搜索参数。

## 输出

JSON 和 TSV 保留查询 ID、种子直系同源、得分、同源组、COG 类别、描述、名称、GO、EC、KEGG KO 和通路字段。

## 示例

```bash
linxira-bio annotation eggnog annotations.tsv normalized.tsv --json
```

## 结果解读

计数反映归一化查询和 GO/KEGG 关联；来源缺失值保持为空，不会推断补齐。

## 注意事项

只归一化既有结果，不执行搜索，也不分发对应数据库。

## 运行时依赖

结果文件存在后，解析和归一化全部在本地 Rust 中运行。

## 引用

记录映射器版本、数据库版本、搜索设置和输入序列来源。

## 故障排除

保留标准 `#query` 表头并避免手工删除列。
