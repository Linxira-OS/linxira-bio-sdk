# 多序列比对共识序列

## 用途

从 FASTA 格式的多序列比对（MSA）中计算共识序列。对于每一列，如果最高频碱基（A、C、G、T、U、N）达到阈值比例则选用，否则使用 N。间隔字符（`-`、`.`）不计入频率统计。

## 输入

一个纯文本或 gzip 格式的 FASTA 比对文件。去除间隔后，所有序列长度必须一致。

## 参数

设置 `--threshold` 范围为 0.0 到 1.0（默认 0.5）。阈值决定碱基被接受所需的最低序列比例；低于阈值的位点标记为 N。

## 输出

一条 ID 为 `consensus` 的 FASTA 记录，包含共识序列。JSON 结果包含输入序列数、比对长度、共识序列长度、模糊位点数、GC 含量百分比及警告信息。

## 示例

```bash
linxira-bio sequence consensus alignment.fa consensus.fa --threshold 0.5 --json
```

## 结果解读

`ambiguous_position_count` 表示没有碱基达到阈值的位点数。单条序列输入会产生警告，但仍会生成有效的共识序列（去除间隔后与输入序列相同）。

## 注意事项

这是一个简单的多数规则共识方法。不平局使用 IUPAC 模糊编码，也不考虑质量分数。全间隔列会被跳过，因此 `consensus_length` 可能小于 `alignment_length`。

## 运行时依赖

仅需本地 Rust；无需 Python、R、Java 或外部可执行文件。

## 引用

多数规则共识是分子系统发育学和序列分析中的标准方法。

## 故障排除

确保所有比对序列的去除间隔后长度一致。已有输出文件不会被覆盖。
