# 蛋白质理化性质

## 用途

对本地蛋白 FASTA 记录计算确定性的序列衍生理化性质。

## 输入

本地普通或 gzip 压缩的蛋白 FASTA。标准氨基酸直接计算；`B`、`J`、`O`、`U`、`X` 和 `Z` 保留为歧义或非标准残基。

## 参数

当前版本没有分析参数。

## 输出

JSON 为每条记录返回长度、残基组成、分子量、理论等电点、pH 7 净电荷、芳香性、GRAVY，以及还原态和氧化态消光系数。

## 示例

```bash
linxira-bio protein properties proteins.faa --json
```

## 结果解读

这些值适用于序列表征和实验规划。分子量单位为道尔顿，消光系数单位为 `M^-1 cm^-1`。

## 注意事项

序列含歧义或非标准残基时，衍生理化值返回 `null`，不会静默编造残基性质。不会推断翻译后修饰、二硫键拓扑、缓冲液或结构状态。

## 运行时依赖

FASTA 解析和计算完全在本地 Rust 中完成，不访问外部数据库。

## 引用

应按所报告指标引用残基质量、Henderson–Hasselbalch 电荷、Kyte–Doolittle 疏水性和序列消光系数方法。

## 故障排除

分析前移除比对缺口和终止符号，并检查含歧义残基记录的警告。
