# 研究队列变异汇总

## 用途

本地汇总多样本 VCF 的研究统计：各 contig 变异数、已调用和缺失基因型、ALT 等位基因拷贝数和携带者基因型数。不会进行致病性分类、诊断或治疗推荐。

## 输入

一份符合规范的多样本 VCF 或 gzip 压缩 VCF。

## 参数

必须提供输入路径；基因型从 `GT` FORMAT 字段读取。

## 输出

返回记录、样本、contig、基因型缺失、携带者基因型和 ALT 等位基因统计。

## 示例

```text
linxira-bio medical variant-cohort cohort.vcf --json
```

## 结果解读

这些是描述性的队列统计，不能说明个体或变异的临床影响。

## 注意事项

结果取决于 VCF 规范化、过滤、样本选择和参考基因组版本。

## 运行时依赖

仅使用本地 Rust；不会上传数据。

## 引用

应引用参考基因组、变异检测器、过滤条件和队列方案。

## 故障排除

请确认 VCF 表头和 GT 字段符合 VCF 规范。
