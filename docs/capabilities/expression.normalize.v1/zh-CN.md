# 表达矩阵标准化

## 用途

使用 CPM、log2-CPM 或中位数比值法在本机标准化完整的 CSV/TSV 批量表达矩阵。

## 输入

第一列为唯一特征标识，其余列为有限且非负的样本数值。支持纯文本和 gzip 输入。

## 参数

用 `--method cpm|log2-cpm|median-ratio` 选择方法。log2-CPM 可设置非负的
`--pseudocount`，默认值为 1。输入与输出路径必须不同。

## 输出

写出保留特征和样本顺序的 TSV。JSON 返回方法、维度、各样本输入/输出总量、
缩放因子和警告。

## 示例

```bash
linxira-bio expression normalize counts.tsv normalized.tsv --method cpm --json
```

## 结果解读

CPM 只校正文库大小；中位数比值法在足够多特征于所有样本中为正时减轻组成偏差；
log2-CPM 适合探索。

## 注意事项

缺失值、重复特征、负值、非有限值和零文库样本会被拒绝。本地数值分析最多处理
1000 万个矩阵单元格；计数模型仍应保留原始计数。

## 运行时依赖

纯 Rust 本地实现，无需 Python、R 或 Java。

## 引用

报告中位数比值标准化时，应引用后续统计方法及其标准化假设。

## 故障排除

先运行矩阵质控，处理缺失值和重复标识，并确认每个样本总量大于零。
