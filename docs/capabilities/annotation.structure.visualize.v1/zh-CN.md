# 注释结构可视化

## 用途

在本地把基因、转录本、外显子、CDS、UTR、motif 或其他 GFF/GTF 特征绘制为确定性的 SVG。

## 输入

通过检查的 GFF3 或 GTF 注释文件。

## 参数

可按特征 ID 或序列 ID 选择区域，并限制最多绘制的特征数。

## 输出

SVG 文件，以及包含尺寸、轨道数、图元数、输出路径和警告的 JSON 元数据。

## 示例

```bash
linxira-bio annotation plot genes.gff3 gene.svg --feature-id gene1 --json
```

## 结果解读

特征坐标按所选区域缩放；颜色区分特征类型，提示信息保留标签和坐标。

## 注意事项

本能力只汇总已有注释记录，不推断缺失的父子关系；不会覆盖已有输出。

## 运行时依赖

由本地 Rust 完成，不需要网络、Python、R 或浏览器。

## 引用

记录注释来源、参考基因组版本、坐标约定和本能力版本。

## 故障排除

确认指定的特征或序列存在；仅在区域仍可读时提高 `--max-features`。
