# M5-G2 wgpu/WGSL 首轮对照（2026-09-30，主机 A）

探针：`gpu-lab gpu-bench`（wgpu 30 / Vulkan 后端 / Intel Arc 130T 核显；同种子合成数据与
M5-G1 CPU 基线逐位一致；计时分相：upload / compute / readback / total）。

## 结论表

| 内核 | GPU（f32/u32） | CPU f64 audit | CPU AVX2+FMA | 一致性 |
| --- | --- | --- | --- | --- |
| pearson-column-pairs（124,750 对 f32） | **compute 17.8 ms / total 18.9 ms** | 381 ms（**21×**） | 88–100 ms（**5–6×**） | Δ=4.14e-6 < 容差 1e-5，**通过** |
| quality-histogram（3 亿碱基，u32 打包） | compute 113.9 ms / total 180.7 ms（含 66.7 ms 上传） | 118 ms（1.04×，打平） | — | **整数精确匹配**（逐 bin checksum 一致），通过 |
| kmer-count | 未移植：哈希表结构不映射 WGSL，按计划留 M5-G3 厂商栈 | 3,578 ms / 783 MB | — | — |

## 解读

1. **计算型内核核显大胜**：Pearson 列对内积在 Arc 130T（核显！）上 21× 于 CPU f64、
   5-6× 于 AVX2+FMA——"最弱硬件（核显）+ f32 推荐档跑出性能"叙事的第一份实测证据，
   且同一输入下 f64 audit 档并存、容差可对账（精度契约落地）。
2. **带宽型内核在 iGPU 上无优势是架构必然**：核显显存即系统内存，3 亿碱基的直方图
   GPU 与 CPU 单线程打平（upload 66.7 ms 还要另付）——该类内核的 GPU 收益要看独立
   显存档（G1/G2），如实记录，不为叙事扭曲数据。
3. **两处实现修正**（过程记录）：① wgpu `DeviceDescriptor::default()` 的 limits 上限
   256 MB，3 亿碱基 buffer 需显式 `required_limits: adapter.limits()`（Vulkan 后端 4 GB）；
   ② 直方图 grid-stride 首版按 workgroup 步进未按线程分摊，256 线程重复计数恰 256 倍
   （checksum 一眼可见），修正为 `group.x * 256 + local_index` 步进 `num_workgroups * 256`。
4. Pearson GPU 版为单 workitem 串行 2000 次 fma（124,750 并行度吃满）；workgroup 内
   tree reduction 与 subgroup 加速留下一轮（预计仍有提升空间）。

复现：`cd gpu-lab && cargo run --release -- gpu-bench`。
