# M5-G2 wgpu/WGSL 首轮对照（2026-09-30，主机 A）

探针：`gpu-lab gpu-bench`（wgpu 30 / Vulkan 后端 / Intel Arc 130T 核显；同种子合成数据与
M5-G1 CPU 基线逐位一致；计时分相 upload / compute / readback，**compute/readback 为 3 次
重复取中位**——稳态口径；upload 为单次 staged 拷贝）。

## 结论表

| 内核 | upload | compute（中位） | CPU f64 audit | CPU AVX2+FMA | 一致性 |
| --- | --- | --- | --- | --- | --- |
| pearson v1（逐线程串行链） | 0.3 ms | 15.7 ms | 145–381 ms（9–24×） | 88–100 ms | Δ=4.14e-6 < 1e-5，通过 |
| **pearson v2（workgroup 树归约）** | 0.4 ms | **3.0 ms**（**48× f64 / 29× AVX2**） | 同上 | 同上 | **Δ=7.42e-7**（比 v1 小 5.6×），通过 |
| quality-histogram（3 亿碱基，u32 打包） | 110 ms（300MB staged） | **18.9 ms（稳态）** | 94–124 ms（**5–6×**） | — | **整数精确匹配**，通过 |
| kmer-count | — | 未移植：哈希表结构不映射 WGSL，按双实现硬规则落 G3 厂商栈（必做不豁免） | 3,578 ms / 783 MB | — | — |

## 解读

1. **v2 树归约速度与精度双赢**：workgroup 内 64 线程按行 stride 分摊 + shared-memory 树归约，
   compute 从 15.7 ms 降至 **3.0 ms**（5.2×），同时 Δ 从 4.14e-6 降至 **7.42e-7**（5.6×）
   ——log-depth 累积误差天然小于 2000 步串行链，精度策略第 2 条规则（长归约用 tree
   reduction）的实效证据。核显 f32 推荐档对 CPU f64 audit 达 **48×**。
2. **直方图结论修正（2026-09-30，median-of-3 规范化后）**：单次冷跑（含首轮冷启动/缓存
   未热）曾测 64–114 ms 与 CPU 打平；3 次重复取中位后**稳态 compute 18.9 ms，比 CPU 快
   5-6×**——数据驻留 device buffer 后的重复 dispatch 显著快于冷启动。两种口径都真实：
   流式单遍场景（每批新数据）接近冷口径；驻留分析场景接近稳态口径。原"iGPU 带宽型无
   优势"结论仅在冷口径成立，按台账规范显式修正而非覆盖。
3. **实现修正记录**（过程）：① wgpu `DeviceDescriptor::default()` limits 上限 256 MB，
   3 亿碱基 buffer 需显式 `required_limits: adapter.limits()`；② 直方图 grid-stride 首版
   未按线程分摊，256 线程重复计数恰 256 倍；③ wgpu dispatch 单维上限 65,536——12.4 万
   workgroup 需二维展开（x×y），shader 以 `num_workgroups.x` 换算线性 index；④ 累加型
   内核（atomicAdd 直方图）重复测量时必须每轮清零输出 buffer，否则计数翻倍。
4. 后续优化空间：v2 每对一组（124,750 组）仍偏保守，subgroup（warp）级 shuffle 归约与
   每组多对的批次化预计仍有余量；与 G3 厂商栈（sycl-rs/cudarc-musa/cutile-rs）同内核
   对照是下一步；750 Ti 将以 cudarc/CUDA 12.x（sm_50）+ Vulkan 双路径实测。

复现：`cd gpu-lab && cargo run --release -- gpu-bench`。
