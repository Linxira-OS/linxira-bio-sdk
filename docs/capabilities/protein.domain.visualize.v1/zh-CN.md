# 蛋白结构域架构可视化

## 用途

把解析后的蛋白结构域命中绘制为确定性的本地 SVG 架构轨道。

## 输入

包含序列坐标的 InterProScan TSV 或受支持的 HMMER domtblout。

## 参数

可选择单条序列，并限制最多序列数和结构域图元数。

## 输出

SVG 文件，以及描述尺寸、序列轨道、结构域图元、路径和警告的 JSON 元数据。

## 示例

```bash
linxira-bio protein domain-plot interproscan.tsv domains.svg --sequence-id protein1 --json
```

## 结果解读

每条水平轨道代表蛋白坐标范围，彩色块表示按坐标排列的结构域命中，并附带 accession 提示。

## 注意事项

重叠命中会同时显示而不会自动裁决；生物学含义取决于数据库版本和搜索阈值。

## 运行时依赖

解析和绘制由本地 Rust 完成，无需网络。

## 引用

记录搜索工具、结构域数据库版本、阈值、输入来源和本能力版本。

## 故障排除

确认输入类型受支持，并确认指定序列至少有一条坐标有效的命中。
